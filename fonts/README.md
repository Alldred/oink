# Fonts

Bundled TrueType fonts for clear e-ink rendering.

| File | Use |
| --- | --- |
| `Nunito-Regular.ttf` | Body / date / labels (primary) |
| `Nunito-Bold.ttf` | Headings and emphasis (primary) |
| `OFL-Nunito.txt` | SIL Open Font Licence for Nunito |
| `weathericons-regular-webfont.ttf` | Day-timeline weather icons |
| `DejaVuSans.ttf` | Fallback body text |
| `DejaVuSans-Bold.ttf` | Fallback bold text |
| `LICENSE` / `AUTHORS` | Upstream DejaVu licence |

[Nunito](https://github.com/googlefonts/nunito) is a soft rounded sans-serif (SIL OFL).
[Weather Icons](https://github.com/erikflowers/weather-icons) by Erik Flowers is SIL OFL 1.1.
DejaVu remains as a fallback — see `LICENSE` for Bitstream Vera / Arev / DejaVu terms.
