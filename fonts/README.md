# Fonts

Bundled [DejaVu Sans](https://dejavu-fonts.github.io/) TrueType fonts for clear e-ink rendering.

| File | Use |
| --- | --- |
| `DejaVuSans.ttf` | Body / date text |
| `DejaVuSans-Bold.ttf` | Time and status message |
| `LICENSE` / `AUTHORS` | Upstream DejaVu licence |

DejaVu fonts are free software — see `LICENSE` for the Bitstream Vera / Arev / DejaVu licence terms.
